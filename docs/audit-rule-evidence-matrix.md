## Распределение по automationLevel

### STRICT — полностью доказуемо (30)

- **№1** — До дедлайна меньше 1 дня
- **№2** — Задача есть в утверждённой смете
- **№3** — Заблокированная задача имеет blocked-тег
- **№5** — Задача содержит описание из ТЗ
- **№6** — Задачи >20 часов декомпозированы
- **№7** — Название и описание проекта сверены с рабочей таблицей
- **№9** — Роль и ставка сверены с рабочей таблицей
- **№10** — Даты и названия спринтов сверены со Scrum
- **№11** — Разделение на типы задач
- **№12** — Названия задач сверены со сметой
- **№13** — ПВ указано в Scrum
- **№14** — High priority / critical bug без движения >24 часов
- **№15** — В работе без обновлений >2 рабочих дней
- **№16** — На проверке без движения >1 рабочего дня
- **№17** — Перегруз QA
- **№18** — Задача без исполнителя
- **№19** — UI-задача имеет ссылку на макет
- **№23** — Нет активных задач без трекинга
- **№24** — Нет трекинга вне рабочего статуса
- **№25** — Факт не превышает ПВ больше чем на 20%
- **№27** — Нет аномального списания за день
- **№28** — Нет готовых задач с нулевым трекингом
- **№30** — У разработчика не больше 3 активных задач
- **№31** — Очередь QA не больше 10 задач
- **№32** — Нет массового старта задач без завершения старых
- **№37** — Давно созданные задачи брались в работу
- **№38** — Название доски по шаблону
- **№39** — В описании доски есть ссылка на папку проекта
- **№40** — В описании доски есть краткое описание проекта из ТЗ
- **№43** — На проверке назначен тестировщик

### TEXT_MARKER — по фиксированным маркерам (10)

- **№4** — Заблокированная задача имеет причину блокировки
- **№20** — Макет согласован
- **№21** — Есть требования к адаптивности
- **№22** — Есть требования к браузерам/устройствам
- **№26** — При превышении ПВ есть комментарий
- **№33** — После успешной проверки есть комментарий "проверено"
- **№34** — Замечания тестировщика имеют скрин/видео/ссылку
- **№35** — При возврате на доработку есть причина
- **№36** — Нет комментариев "готово/сделал/проверь" без деталей
- **№42** — Нет незакрытых вопросов "уточнить/обсудить/ждем ответ/непонятно"

### PARTIAL — автоматизация неполная (4)

- **№8** — Состав команды сверен с рабочей таблицей и Discord
- **№29** — Нет большого трекинга без результата/комментариев
- **№41** — Открытые вопросы в комментариях закрыты
- **№45** — Названия задач и время готовы к актам

### SOURCE_UNAVAILABLE — источник недоступен (1)

- **№44** — Нет задач на уволенных/неактивных сотрудниках

### MANUAL_REQUIRED — нужна ручная проверка (0)

## Детализация по проверкам

### №1. До дедлайна меньше 1 дня

- **ruleIds:** deadline_less_than_one_day
- **automationLevel:** STRICT (да)
- **Источники:** AppTask DB: deadline/dueDate, status
- **Scope:** активные task-level карточки (не потоковые)
- **Candidates:** не завершены; дедлайн задан; до дедлайна < 24 ч
- **Violation:** candidate не завершён и дедлайн < 24 ч (WARN) или просрочен (FAIL)
- **Passed:** candidates без нарушения (нет таких задач в зоне < 24 ч)
- **Not checked:** —
- **Итог OK:** candidates = 0 → «Кандидатов для проверки нет»; не писать «64 кандидатов»
- **Итог PARTIAL:** —
- **Итог SKIP:** —

### №2. Задача есть в утверждённой смете

- **ruleIds:** scrum_task_in_estimate
- **automationLevel:** STRICT (да)
- **Источники:** AppTask task id/title; Scrum / утверждённая смета
- **Scope:** task-level карточки
- **Candidates:** все карточки при доступной смете
- **Violation:** задача не найдена в утверждённой смете
- **Passed:** задача найдена в смете
- **Not checked:** Scrum / смета недоступна
- **Итог OK:** все задачи в смете
- **Итог PARTIAL:** —
- **Итог SKIP:** смета не загружена

### №3. Заблокированная задача имеет blocked-тег

- **ruleIds:** blocked_tag_present
- **automationLevel:** STRICT (да)
- **Источники:** AppTask tags, status/stage (blocked)
- **Scope:** заблокированные task-level карточки
- **Candidates:** статус/этап содержит blocked / блокер
- **Violation:** нет тега blocked/блок
- **Passed:** тег blocked присутствует
- **Not checked:** —
- **Итог OK:** 0 заблокированных → «Кандидатов для проверки нет»

- **Итог OK:** описание OK
- **Итог PARTIAL:** —
- **Итог SKIP:** —

### №41. Открытые вопросы в комментариях закрыты

- **ruleIds:** open_questions_closed
- **automationLevel:** PARTIAL (частично)
- **Источники:** AppTask comments
- **Scope:** комментарии task-level карточек
- **Candidates:** комментарии с «?» или маркерами вопроса (вопрос, уточнить, обсудить, ждем ответ, непонятно)
- **Violation:** вопрос-кандидат без ответа другого участника
- **Passed:** ответ найден или нет вопросов-кандидатов
- **Not checked:** невозможно связать вопрос и ответ (автор/время)
- **Итог OK:** 0 вопросов-кандидатов → «по найденным маркерам не найдено»
- **Итог PARTIAL:** связь вопрос→ответ эвристическая → PARTIAL, не уверенный OK
- **Итог SKIP:** —
- **Формулировка в отчёте:** проверено частично; показать stats: комментарии, «?», кандидаты

### №42. Нет незакрытых вопросов "уточнить/обсудить/ждем ответ/непонятно"

- **ruleIds:** unresolved_question_keywords_in_card
- **automationLevel:** TEXT_MARKER (частично)
- **Источники:** AppTask title, description, comments
- **Scope:** активные task-level карточки
- **Candidates:** текст с маркерами: уточнить, обсудить, ждем ответ, ждём ответ, непонятно
- **Violation:** маркер в активной карточке без закрывающего комментария
- **Passed:** маркеров нет или закрыты
- **Not checked:** —
- **Итог OK:** 0 совпадений → показать маркеры и поля поиска
- **Итог PARTIAL:** —
- **Итог SKIP:** —
- **Формулировка в отчёте:** по фиксированным текстовым маркерам

### №43. На проверке назначен тестировщик

- **ruleIds:** review_stage_requires_assignee
- **automationLevel:** STRICT (да)
- **Источники:** AppTask status, assignees
- **Scope:** карточки на этапе проверки / QA
- **Candidates:** текущий статус ∈ review/QA
- **Violation:** исполнитель (тестировщик) не назначен

- **Not checked:** —

- **Итог PARTIAL:** —
- **Итог SKIP:** —

### №44. Нет задач на уволенных/неактивных сотрудниках

- **ruleIds:** blocked_assignee_not_allowed
- **automationLevel:** SOURCE_UNAVAILABLE (нет)
- **Источники:** AppTask assignees; AppTask users API (blocked)
- **Scope:** task-level с назначенным исполнителем
- **Candidates:** назначения на исполнителей
- **Violation:** исполнитель blocked в AppTask
- **Passed:** исполнитель активен
- **Not checked:** источник «уволенные/неактивные» не подключён — только blocked users
- **Итог OK:** нет blocked assignees
- **Итог PARTIAL:** источник уволенных недоступен → PARTIAL + «Не проверено»
- **Итог SKIP:** users API недоступен
- **Формулировка в отчёте:** требует ручной проверки списка уволенных

### №45. Названия задач и время готовы к актам

- **ruleIds:** act_ready_naming
- **automationLevel:** PARTIAL (частично)
- **Источники:** AppTask title; status (завершённые); Scrum ПВ (косвенно)

- **Candidates:** завершённые задачи
- **Violation:** название не готово к акту
- **Passed:** название OK
- **Not checked:** фактическое время и ПВ — отдельные правила, здесь не проверяются
- **Итог OK:** 0 завершённых или все OK по названию
- **Итог PARTIAL:** проверено частично: только название
- **Итог SKIP:** —
- **Формулировка в отчёте:** время и ПВ — отдельные правила
